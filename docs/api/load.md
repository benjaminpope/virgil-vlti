# `virgil_vlti.load`

`to_oidata` reads calibrated OIFITS files and the nuisance modes beside them into a virgil `OIData`, with `with_gains(modes=...)` and `with_closure_offsets(modes=...)` set and aligned sample for sample with virgil's own window and observable selection. It needs virgil (`pip install virgil-vlti[virgil]`).
